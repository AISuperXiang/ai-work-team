# Security Standard

## 禁止项

- 禁止硬编码密钥、密码、Token、Cookie、私钥和内部凭据。
- 禁止绕过权限、鉴权、审计和风控。
- 禁止在日志中输出敏感信息。
- 禁止把内部配置或调试接口暴露到用户可访问路径。

## 必查项

- 输入校验。
- 权限校验。
- 敏感数据脱敏。
- 错误信息不泄露内部实现。
- 依赖和脚本不引入未知外部执行风险。

## 数据安全

涉及个人信息、支付、权限、业务配置或运营数据时：

- 明确数据来源。
- 明确访问权限。
- 明确留存和删除策略。
- 明确审计和回滚能力。

## 交付要求

发现安全风险时必须按 P0/P1/P2 标注影响，不得只作为普通优化项处理。
