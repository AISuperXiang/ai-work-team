# Engineering Standards

本目录维护研发规范。工作流进入技术方案、实现、测试或交付阶段时按需加载。

## 文件

- `code-change-standard.md`：代码改动约束。
- `technical-design-standard.md`：技术方案规范。
- `testing-standard.md`：测试规范。
- `review-standard.md`：评审规范。
- `release-standard.md`：发布规范。
- `security-standard.md`：安全规范。
- `cli-quality-architecture.md`：CLI 严格参数、文件写入、行为测试、突变和 CI 架构。

## 原则

- 先遵循目标仓库已有规范。
- 本目录只提供默认底线。
- 任何偏离规范的做法必须说明原因和风险。
