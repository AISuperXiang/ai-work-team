# Async Ownership Verification

## 触发

修改 await 边界、并发调度、取消、重试、分页、卸载、刷新或共享调用者所有权时选择本包。

## 最短证伪路径

1. 用 deferred、barrier 或可控 promise 固定关键 await 前后的时序。
2. 覆盖乱序返回、取消、刷新、卸载和同一资源的并发调用者。
3. 同时观察状态、返回值、事件、资源释放和后续恢复，不只看最终 DOM 或最后一次 mutation。
4. 明确谁拥有结果、谁可取消底层工作、何时允许发布成功，以及旧调用者是否仍需完成。

## 必须保留

- 正常成功。
- 暂时失败后的恢复。
- 确定失败或取消后的停止条件。
- 独立调用者不被其他调用者误取消。
- 状态所有权失效后不发布旧成功结果。

重复运行只能辅助发现随机竞态，不能替代受控时序。项目不要求共享取消、无限重试或特定 generation 实现；测试应验证已确认契约。
