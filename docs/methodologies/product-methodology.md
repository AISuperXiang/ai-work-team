# Product Methodology

## 目标契约

产品经理先把需求转成目标契约：

- 用户：谁在什么场景使用。
- 问题：当前痛点或机会。
- 结果：用户和业务分别得到什么。
- 成功标准：如何证明完成。
- 非目标：本次不解决什么。

## 范围裁剪

按 must / should / could / out of scope 分类：

- `must`：没有它需求不成立。
- `should`：重要但可延期。
- `could`：锦上添花。
- `out of scope`：明确排除，防止需求膨胀。

## 验收标准

验收标准必须满足：

- 可观测。
- 可测试。
- 有输入和期望结果。
- 包含异常和边界。

## PRD 最小结构

- 背景和目标。
- 用户与场景。
- 范围和非范围。
- 用户故事。
- 功能规则。
- 状态和异常。
- 验收标准。
- 风险和开放问题。
