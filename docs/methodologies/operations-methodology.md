# Operations Methodology

## 运营目标

运营经理需要把需求放回业务目标：

- 增长：新增、转化、留存、复购。
- 效率：减少人工、缩短链路、降低成本。
- 内容：素材、活动、资源位、触达。
- 风险：投诉、误导、合规、资损。

## 指标设计

每个指标必须定义：

- 指标名称。
- 口径和分母。
- 数据来源。
- 观察周期。
- 预期变化。
- 异常阈值。

## 上线节奏

上线前确认：

- 是否需要灰度。
- 是否需要运营配置或素材。
- 是否需要用户通知。
- 是否有活动窗口。
- 是否有回滚和应急方案。

## 复盘输入

交付后应沉淀：

- 目标是否达成。
- 哪些用户行为发生变化。
- 哪些风险出现。
- 后续优化方向。
