# UI Methodology

## 用户路径优先

UI 设计先回答：

- 用户从哪里来。
- 用户要完成什么。
- 用户下一步去哪里。
- 哪些信息影响用户决策。

## 状态矩阵

至少覆盖：

- 默认态。
- 加载态。
- 空态。
- 错误态。
- 成功态。
- 禁用态。
- 权限不足。
- 长文本和极端数据。

## 可用性检查

- 层级是否清楚。
- 点击目标是否足够。
- 文案是否直接说明动作和结果。
- 表单错误是否能定位。
- 移动端是否可读和可操作。

## 走查方法

实现后按以下顺序走查：

1. 对照需求路径。
2. 对照设计状态。
3. 检查视觉层级和间距。
4. 检查交互反馈。
5. 检查响应式和可访问性。
